Open-Atorch-T3

Open-source custom firmware, board support package (BSP), WebBLE dashboard, and flash/recovery tools for the ATORCH / JUWEI T3 USB-C power meter.

Install Firmware Feature & Test Matrix Source on GitHub

Hardware Overview

Verified hardware platform & sensors of the ATORCH / JUWEI T3 (documented in detail in AGENTS.md).

SoC & Storage

Zhuhai JieLi AC707N (BR35, pi32v2 up to 288 MHz, 2D GPU) with 2 MB SPI NOR flash (DTR mode).

Display & Touch

1.54" IPS 240×240 (ST7789V over hardware JL_DBI, PWM backlight IO_LCD_PG) + CST816D touch on I2C0.

Precision Metering

INA226 (1.2–50 V, bidirectional 5 mΩ shunt), PA10 GPADC for AC ripple + 256-pt FFT, PC02/PC03 for D-/D+, PB00 NTC.

Sensors & Wireless

SC7A20 (3-axis accelerometer), ENS220 or BMP280 (barometer), vibration motor (IO_MT_PG), BLE 5.4 + WebBLE.

Build & Installation Guide

Reproducible build & flash pipeline for Windows (PowerShell) using the Docker toolchain.

Mandatory Before Flashing: Create a Full 2 MB Backup! Flash offsets starting at 0x138000 hold your factory calibration (VM), Bluetooth data (BTIF), and MAC address (key_mac). Always pull a full backup first. You also need the stock file T3 Firmware Version-UP 2.0.4.bin locally in the project root, because pack_t3_slot.py extracts the 54,048-byte OEM resource SDFILE from it (excluded from GitHub for licensing reasons).
1

Install Prerequisites

Required: Docker Desktop (linux/amd64 containers), Git, Python 3.10+ (with .venv), and libusbk/WinUSB drivers for jl-uboot-tool if needed.

2

Clone Repository & Fetch JieLi AC707N SDK

The proprietary JieLi SDK is not hosted on GitHub and is downloaded locally once:

git clone --recursive https://github.com/ThomasSebastianLE/Open-Atorch-T3.git
cd Open-Atorch-T3
.\scripts\setup-sdk.ps1
3

Pull Full Device Backup (Run as Administrator)

Verifies the USB ROM bootloader hook and saves a complete 2 MB dump under backups/:

.\.venv\Scripts\python.exe .\scripts\enter_uboot.py --probe
.\scripts\backup-device.ps1
4

Compile Firmware & Pack 0x5000 Slot

Applies the BSP overlay, compiles inside the Ubuntu container with pi32v2 Clang, and generates the scrambled slot binary:

.\scripts\build.ps1 -Project meter
5

Flash Firmware to the ATORCH T3

Reboots the device into the bootloader (BR35UBOOT1.00), flashes t3-meter-fw-slot.bin, and performs a readback verification:

.\scripts\flash-slot.ps1 -SlotPath .\firmware-builds\t3-meter-fw-slot.bin

Emergency Recovery (Unbrickable)

Even if a custom firmware fails to boot, the factory USB-HID IAP bootloader always remains accessible.

!

Restore via USB-HID IAP (ATORCH T3 V1.0.1)

Hold both physical buttons on the T3 simultaneously while plugging in the USB cable (display shows product updating / chann usb hid). Then restore the stock firmware: 

.\.venv\Scripts\python.exe .\scripts\atorch_iap_flash.py "T3 Firmware Version-UP 2.0.4.bin"
